## 1단계. 앱 파일 받기 (컴퓨터에서) 💻

1. 작업 공간의 **`SK-성경-앱-v1.6.1.zip`** 파일을 컴퓨터로 내려받습니다.
2. 파일을 **마우스 오른쪽 버튼 → "압축 풀기"(또는 "모두 압축 풀기")** 합니다.
3. 폴더 안에 **파일 44개**가 폴더 없이 한 곳에 들어 있습니다. (`App.tsx`, `index.html`, `nkrv.json`, `package.json`, `wrangler.jsonc` …)
   - 이 앱은 일부러 **폴더 없이** 만들었습니다. 그래서 파일을 한 번에 골라 올리기만 하면 됩니다.

## 2단계. GitHub에 새 저장소 만들고 파일 올리기 📁

### 2-1. 새 저장소(Repository) 만들기
1. 컴퓨터의 Chrome(또는 Edge)에서 **https://github.com** 에 로그인합니다.
2. 오른쪽 위 **＋** 버튼 → **New repository**를 누릅니다.
   (또는 주소창에 `https://github.com/new`를 입력)
3. 아래처럼 입력합니다.

   | 항목 | 입력할 값 |
   |---|---|
   | **Repository name** | `sk-bible` |
   | Description | (비워도 됨) |
   | 공개 여부 | 🔒 **Private** ← **꼭 선택** |
   | Add a README file | ☐ **체크하지 않음** |
   | .gitignore / license | **None** 그대로 |

4. 맨 아래 초록색 **Create repository**를 누릅니다.

### 2-2. 파일 올리기
1. 저장소 화면에서 **Add file**(또는 **＋**) → **Upload files**를 누릅니다.
   (빈 저장소라면 "Quick setup…" 화면의 파란 글씨 **"uploading an existing file"**)
2. 가운데 상자의 **choose your files**를 누릅니다.
3. 파일 선택 창에서 압축을 푼 폴더로 들어가 **Ctrl + A**(전체 선택) → **열기**를 누릅니다.
   - 끌어다 놓아도 됩니다.
4. 파일 44개가 목록에 올라갈 때까지 기다립니다. (10~30초)
5. 아래 초록색 **Commit changes**를 누릅니다.
6. 저장소 첫 화면에 `App.tsx`, `index.html`, `nkrv.json`, `package.json`, `wrangler.jsonc` 등이 보이면 성공입니다. ✅

## 3단계. Cloudflare Pages로 앱 주소 만들기 🏗️

1. **https://dash.cloudflare.com** 에 로그인합니다.
2. 왼쪽 메뉴에서 **Workers & Pages**(또는 **Compute (Workers)**)를 누릅니다.
   - 메뉴가 안 보이면 왼쪽 위 **☰**를 누르세요.
3. 오른쪽 위 파란 버튼 **Create application**(또는 **Create**)을 누릅니다.
4. 위쪽 탭에서 **Pages**를 고릅니다.
   - 탭이 없고 Workers 화면만 나오면, 화면 아래쪽의 **"Looking to deploy Pages? Get started"** 링크를 누르세요.
5. **Import an existing Git repository**(또는 **Connect to Git**)의 **Get started**를 누릅니다.
6. **GitHub** 계정이 보입니다.
   - 목록에 `sk-bible`이 **안 보이면**: **Configure GitHub App**(또는 + Add account)을 누릅니다. GitHub 화면에서 **Repository access → Only select repositories**에 `sk-bible`을 추가하고 **Save** → Cloudflare 화면으로 돌아옵니다.
7. **`sk-bible`**을 고르고 → **Begin setup**을 누릅니다.
8. **Set up builds and deployments** 화면에서 아래처럼 맞춥니다.

   | 항목 | 값 |
   |---|---|
   | **Project name** | `sk-bible` (이 이름이 주소가 됩니다) |
   | **Production branch** | `main` |
   | **Framework preset** | `React (Vite)` (목록에 없으면 `None`) |
   | **Build command** | `npm run build` |
   | **Build output directory** | `dist` |
   | Root directory / Environment variables | (비워 둠) |

9. **Save and Deploy**를 누릅니다.
10. 글자들이 지나가며 1~3분 뒤 **"Success! Your project is deployed"**가 나옵니다.
11. 화면에 나온 **주소**를 확인합니다.
    - 보통 **`https://sk-bible.pages.dev`**
    - 이름이 이미 쓰이고 있으면 `https://sk-bible-abc.pages.dev`처럼 뒤에 글자가 붙습니다.
    - 📝 **이 주소를 꼭 메모해 두세요!**
12. 컴퓨터에서 그 주소를 열어 창세기 1장이 나오면 성공입니다. ✅

### 💡 Pages가 아니라 Workers로 만들어졌다면?
빌드 설정에 **Deploy command: `npx wrangler deploy`**가 보이면 Workers로 만들어진 것입니다. 이 경우에도 괜찮습니다.
- 저장소에 **`wrangler.jsonc`** 파일이 있으면 정상적으로 배포됩니다. (zip에 포함되어 있습니다)
- 주소는 `https://sk-bible.<내계정이름>.workers.dev` 형태입니다.
  **sk-bible → Overview** 화면 오른쪽의 **Domains & Routes**(또는 **Visit** 버튼)에서 확인할 수 있습니다.

## 4단계. Galaxy S24에 설치하기 📱⭐

### 방법 ①: 삼성 인터넷 (S24 기본 브라우저)
1. 폰에서 **삼성 인터넷**(파란 행성 아이콘)을 엽니다.
2. 주소창에 3단계의 주소(예: `sk-bible.pages.dev`)를 입력합니다.
3. 창세기 1장이 보이면,
4. 주소창 오른쪽의 **⬇ 설치 아이콘**을 누르고 → **설치**를 누릅니다.
   - 아이콘이 없으면: 아래 **≡ (메뉴)** → **＋ 현재 페이지 추가** → **홈 화면**
5. 홈 화면에 **SK-성경** 아이콘이 생깁니다. 🎉

### 방법 ②: Chrome
1. **Chrome**에서 주소를 엽니다.
2. 오른쪽 위 **⋮** → **홈 화면에 추가**(또는 **앱 설치**) → **설치**

### ✅ 오프라인 확인
1. 홈 화면의 **SK-성경** 아이콘으로 엽니다. (주소창 없는 앱 화면이면 정상)
2. **비행기 모드 ✈️**를 켭니다.
3. 최근 앱 버튼(▯▯▯)을 누르고 SK-성경을 **위로 밀어 닫은 뒤** 다시 엽니다.
4. 성경이 그대로 나오면 성공입니다! ✅ (비행기 모드는 다시 끄세요)

### 👫 아내 폰에 설치
1. 카카오톡으로 **앱 주소**를 보냅니다.
2. 아내 폰에서 링크를 열고 **⋮ → "다른 브라우저로 열기"** → **삼성 인터넷** 또는 **Chrome**을 고릅니다.
   (⚠️ 카카오톡 안의 화면에서는 설치가 안 됩니다)
3. 위의 방법 ① 또는 ②로 설치합니다.

**🎉 설치 끝!**

## 📖 SK-성경 사용법

### 화면 구성
| 위치 | 기능 |
|---|---|
| **아래 페이지 버튼** | 서로 다른 성경 페이지 1~10개 (한 화면에 항상 5개가 보이고, 6개부터는 버튼 줄을 옆으로 밀어서. 긴 책 이름은 칸에 맞춰 글씨가 작아짐). 앱을 켜면 항상 **페이지 1**이 나옵니다. 각 버튼에 지금 읽는 곳이 **"창세기 / 2장 10절"**처럼 표시됩니다 |
| 오른쪽 위 🔖 **북마크** | 저장한 구절 (메모, 복사, 삭제) |
| 오른쪽 위 🔍 **검색** | 단어 검색 / **문장으로 찾기 (AI 설명)** |
| 오른쪽 위 ⚙ **설정** | 글자 크기, 줄·절 간격, 좌우 여백, 화면 밝기, 복사 형식, 백업, 버전 |

### 📱 뒤로 버튼
- 폰의 **뒤로** 버튼을 누르면 앱이 꺼지지 않고 **이전 화면**으로 돌아갑니다.
  (예: 검색 → 구절 열기 → 뒤로 = 검색 결과로, 한 번 더 = 검색 전에 읽던 곳으로)
- 책 선택 창이나 절 선택이 열려 있으면 먼저 그것을 닫습니다.
- 더 돌아갈 곳이 없으면 "한 번 더 누르면 종료됩니다"가 뜨고, 2초 안에 한 번 더 누르면 닫힙니다.

### 성경 이동
- 위쪽 **"창세기 1장 ▾"**를 누르면 구약/신약 → 책 → 장을 고릅니다.
- **빠른 이동**: `요3:16`, `시23`, `요한복음 3장 16절`을 입력하고 **이동**을 누릅니다.
- **장 넘기기**: 본문을 **좌우로 밀면** 다음 장이 손가락을 따라 부드럽게 넘어옵니다. 장 맨 아래의 **‹ 이전 장 / 다음 장 ›** 버튼도 같습니다.
- 맨 왼쪽 **‹**를 누르면 검색이나 북마크로 이동하기 **전에 읽던 곳으로** 돌아갑니다.

### 구절 복사 · 북마크 · 형광펜 · 원어설명 · 해설 · 암송 · 공유
1. 구절을 **누르면** 선택됩니다. 여러 절을 누르면 함께 선택됩니다.
2. **길게 누르면** 범위 선택이 됩니다. (16절을 누른 뒤 → 20절을 길게 누르면 16~20절)
3. 아래 메뉴에서 **복사 / 북마크 / 형광펜 / 원어설명 / 해설 / 암송 / 공유(카카오톡)**를 누릅니다.
4. 폰의 **뒤로가기**를 누르면 선택이 풀립니다.

```
(마태복음 5:4)
애통하는 자는 복이 있나니 그들이 위로를 받을 것임이요
```

### 📜 원어설명
- 구절을 고르고 **원어설명**을 누르면:
  - 구약은 **히브리어**(레닌그라드 사본), 신약은 **헬라어**(NA28) 원문
  - **🔍 단어별 분석**: 원어 · 한글 발음 · 뜻 · 사전형 · 스트롱 번호 · 문법(예: *동사 현재 능동 분사 주격 복수 남성*)
  - **AI 원어 해설**: 핵심 단어의 깊은 뜻, 시제·태가 주는 의미, 번역에서 잘 안 보이는 뉘앙스
- 여러 절을 고르면 위에 `5:3 5:4 …` 버튼이 생겨 하나씩 볼 수 있습니다.
- 원어 자료는 처음 한 번만 받으면(성경 부분마다 0.3~1.3MB) 인터넷 없이도 보입니다. AI 해설은 인터넷이 필요하고, 한 번 본 해설은 폰에 저장됩니다.

  - 해설 한 번에 **30초~1분** 걸립니다 (한 번 만든 해설은 저장되어 바로 나옴). 무료 사용량 안에서 하루 20~30번 정도가 적당합니다.
  - 아래 **"א Ω 원어설명"** 버튼을 누르면 같은 구절의 원어설명으로 바로 넘어갑니다.
- **🔗 관련 구절** (관주, 인터넷 필요 없음): 이 절과 연결된 성경 구절을 많이 연결된 순서로 최대 12곳까지 보여 줍니다.
  구절을 누르면 펼쳐지고, **"이 말씀으로 가기 →"**를 누르면 그곳으로 이동합니다. **뒤로 버튼**을 누르면 원래 읽던 곳으로 돌아옵니다.
  여러 절을 골랐다면 위의 `5:3 5:4` 버튼으로 절을 바꿉니다. (자료: OpenBible.info, CC BY)
- **📚 낱말·인물** (AI): 어려운 낱말 풀이(예: 애통 → 몹시 슬퍼함)와 본문에 나오는 인물·지명 설명을 보여 줍니다.
  맨 아래 **직접 물어보기** 칸에 *궁창*, *아브라함*, *가버나움*처럼 아무 낱말이나 써서 물어볼 수 있습니다.
- AI 결과는 폰에 저장되어 다시 열면 바로 나옵니다. 마음에 안 들면 **↻ 다시 해설**을 누르세요.

### 🏛️ 장 배경 카드
- 장 이름 아래 **장 주제 상자를 누르면**(*배경 보기 ▼*) 배경 카드가 펼쳐집니다.
  이 장 요약 · 🕰️ 시대 · 📍 장소 · 👥 인물 · 🔗 앞 장과의 흐름 · ⭐ 핵심 구절이 나옵니다. 핵심 구절을 누르면 그 절로 이동합니다.
- 다시 누르면 접힙니다(*접기 ▲*). 한 번 만든 카드는 폰에 저장됩니다.

### 📘 성경 66권 소개 (인터넷 필요 없음)
- **책 선택 화면**에서 책을 누르면 장 번호 위에 **"📘 ○○ 소개"**가 나옵니다. 눌러서 펼치면 요약, 저자, 시대, 분량, 🧭 한눈에 보는 구조, ⭐ 핵심 구절이 보입니다.
  구조의 각 부분이나 핵심 구절을 누르면 그곳으로 바로 이동합니다.
- 각 책의 **1장 맨 위**에도 같은 소개가 접힌 채로 나옵니다.
- 오바댜, 빌레몬서처럼 1장뿐인 책도 이제 장 선택 화면이 한 번 나옵니다(소개를 보실 수 있게).

### 🧠 암송 카드
1. 외우고 싶은 절을 고르고 **암송**을 누르면 카드가 생깁니다. (여러 절을 골라 한 장의 카드로 만들 수 있습니다)
2. 오른쪽 위 **북마크** → 위의 **🧠 암송 카드** 탭을 누릅니다.
3. **▶ 오늘 복습**을 누르면 연습이 시작됩니다. 연습 방법은 네 가지입니다.
   - **첫 글자**: `심·· 가·· 자· 복· …`처럼 첫 글자만 보입니다. 낱말을 누르면 그 낱말이 보입니다.
   - **빈칸**: 낱말 몇 개가 빈칸이 됩니다. 빈칸을 누르면 하나씩 보입니다.
   - **가리기**: 장절만 보고 외운 뒤, 눌러서 확인합니다.
   - **전체 보기**: 처음에 여러 번 소리 내어 읽을 때 씁니다.
4. 끝나면 **😊 외웠어요** 또는 **😅 다시 외우기**를 누릅니다.
   외웠어요를 누를 때마다 다음 복습이 **1일 → 3일 → 7일 → 14일 → 30일** 뒤로 늘어나고, 5번 외우면 **다 외움**이 됩니다.
   다시 외우기를 누르면 처음 단계부터 다시 시작합니다.
- 암송 카드는 설정의 **백업 파일**에도 함께 저장됩니다.

### 📌 단락 소제목 · 장 주제
- **단락 소제목**: 성경책에 있는 그대로의 **개역개정 소제목**이 단락이 시작하는 절 위에 나옵니다.
  예) 마태복음 5장 → *복이 있는 사람 (눅 6:20-23)*, *소금이요 빛이라*, *예수와 율법* …
  예) 로마서 10장 16절 위 → *믿음과 들음과 그리스도의 말씀*
  앱 안에 들어 있어서 **모든 장에 바로**, 인터넷 없이도 나옵니다.
  (시편은 소제목 대신 본문 맨 앞 [다윗의 시] 같은 표제가 그대로 나옵니다. 앞 장에서 이어지는 장은 소제목이 없을 수도 있습니다.)
- **장 주제**: 장 이름 바로 아래 색 상자에 그 장 전체를 한 줄로 요약한 문장이 나옵니다.
  처음 여는 장은 AI가 만드는 동안 *"장 주제를 만드는 중…"*이 보이고, 몇 초 뒤 주제로 바뀝니다. 한 번 만든 주제는 폰에 저장되어 그다음부터는 바로, 인터넷 없이도 나옵니다.
  못 만들면 *"장 주제를 못 만들었어요 · 눌러서 다시 시도"*가 나옵니다. 누르면 다시 만듭니다.
- 끄기: **설정 → 장 주제 보기 / 단락 소제목 보기**. 주제가 마음에 안 들면 **설정 → 기타 → 장 주제 다시 만들기**.

### 🔍 검색 — 두 가지 방법
**🔤 단어 검색**
- `사랑` → 그 단어가 들어 있는 모든 구절
- `믿음 소망` → 두 단어가 **모두** 들어 있는 구절
- 결과가 없으면 **"문장으로 찾기"**로 바로 다시 찾아볼 수 있습니다.

**💬 문장으로 찾기** ⭐
- 구절이 정확히 기억나지 않을 때 **기억나는 대로** 쓰면 비슷한 구절을 찾아줍니다.
- **인터넷이 되면 맨 위에 AI 설명 카드**가 나옵니다. 키보드의 🎤 음성 입력으로 말해도 됩니다. 오타가 있어도 AI가 알아듣습니다.
  - 예) *노화와 모세와 달리 이따 할지라도 자기만 권원을 받는다는 성역구절은*
    → "질문하신 내용은 에스겔 14장 14절과 20절 말씀입니다" + 질문 풀이 + 📖 개역개정 본문(열기·복사) + 💡 핵심 의미
  - 구절 본문은 AI가 쓴 것이 아니라 **앱에 들어 있는 개역개정 본문**을 그대로 보여 줍니다.
  - AI 설명은 참고용입니다. 가끔 틀릴 수 있으니 본문을 꼭 확인하세요.
  - 끄고 싶으면 **설정 → 문장으로 찾기에 AI 설명** 끄기.
- AI 카드 아래에는 인터넷 없이 폰 안에서 찾은 **글자가 비슷한 구절**이 함께 나옵니다.
- 띄어쓰기나 말끝(~다, ~라)이 달라도 괜찮습니다.

| 이렇게 쓰면 | 이 구절을 찾아줍니다 |
|---|---|
| 하나님이 세상을 너무 사랑해서 아들을 보내주셨다 | **요 3:16** |
| 여호와는 내 목자라 부족함 없다 | **시 23:1** |
| 능력 주시는 분 안에서 모든 것을 할수있다 | **빌 4:13** |
| 네 길을 여호와께 맡기면 이루어 주신다 | **시 37:5** |
| 사랑은 오래 참고 친절하다 | **고전 13:4** |

- 맨 위에 **"가장 비슷"** 표시가 붙고, 오른쪽 막대가 길수록 더 비슷한 구절입니다.
- 입력한 문장과 겹치는 글자는 **노란색**으로 표시됩니다.
- 성경에 나오는 낱말이 많이 들어갈수록 잘 찾습니다. 다만 "걱정하지 말라는 말씀"처럼 **뜻만 설명하는 문장**은 잘 찾지 못합니다.

**공통**: 범위(전체·구약·신약·지금 보는 책)를 고를 수 있고, 위의 **"열 페이지"**에서 결과를 열 페이지를 고릅니다.

### 설정
- **성경 글자 크기**: 작게·보통·크게·아주 크게, 또는 슬라이더 (성경 본문만)
- **성경 제목 크기**: 본문 위의 "전도서 8장" 같은 제목 (기본 22)
- **메뉴 글씨**: 버튼·탭·제목줄·아래 페이지 버튼 (기본 20)
- **설명 글씨**: AI 해설·장 주제·소제목·66권 소개·낱말 풀이·안내문 (기본 20)
- "처음 크기로" 버튼을 누르면 제목 22 · 메뉴 20 · 설명 20으로 돌아갑니다
- **화면**: ☀️ 밝게 / 📜 종이색 / 🌙 어둡게, 고딕체/명조체
- **줄 간격**(1.0부터), **절 간격**, **좌우 여백**(0 = 화면 끝까지 꽉 차게)
- **절 번호 위치**: 글 앞에(꽉 차게) / 왼쪽 칸에
- **줄 바꿈**: 글자 단위(좌우 끝이 반듯하게 꽉 참) / 낱말 단위
- **버전**: 지금 버전과 업데이트 시각, 최신 버전인지 표시. 앱은 켤 때마다 새 버전을 확인해 자동으로 바뀝니다.
- 화면 꺼짐 방지, 좌우로 밀어 장 넘기기, 페이지 개수(1~10)
- 복사 형식 (요한복음 / 요, 장절을 위 또는 아래에, 절 번호)
- **백업 파일 내보내기 / 불러오기** — 폰을 바꿀 때 북마크와 형광펜을 옮기는 용도

### 자동 저장
- 각 페이지의 **읽던 위치**가 자동으로 저장되어, 껐다 켜도 그대로 돌아옵니다.

> ⚠️ 북마크와 형광펜은 **폰 안에만** 저장됩니다. 앱을 지우거나 폰을 바꾸기 전에는
> **설정 → 백업 파일 내보내기**로 파일을 저장해 두세요. (카카오톡 "나와의 채팅"이나 구글 드라이브에 보관)

## ❓ 문제 해결

| 증상 | 해결 방법 |
|---|---|
| 설치 메뉴가 안 보여요 | 카카오톡이나 네이버 앱 안의 화면이 아닌 **삼성 인터넷 / Chrome 앱**에서 여세요 |
| Cloudflare에서 Failed가 떠요 | 2-2의 6번처럼 저장소 첫 화면에 `package.json`이 **바로** 보이는지 확인하세요. Build command `npm run build`, output `dist`도 확인하세요 |
| 친구에게 보낸 주소가 안 열려요 | ① 카카오톡 안에서 열지 말고 링크를 길게 눌러 복사 → **Chrome / 삼성 인터넷** 주소창에 붙여넣기 ② 주소가 정확히 `https://sk-bible.psungkim.workers.dev/` 인지 (앞뒤에 `++`, `)`, 띄어쓰기 등이 붙지 않았는지) ③ 회사·학교 와이파이에서는 막힐 수 있으니 **와이파이를 끄고 모바일 데이터**로 시도 ④ 처음 한 번은 성경 본문(약 1.3MB)을 받느라 몇 초 걸릴 수 있어요 |
| 고친 내용이 폰에 반영되지 않아요 | 앱을 완전히 닫았다가 **두 번** 여세요 |
| 문장으로 찾기의 첫 검색이 느려요 | 처음 한 번은 검색 준비(약 1초)를 합니다. 그다음부터는 바로 나옵니다 |

## 🛠 (참고) 개발자용 메모
```bash
npm install
npm run dev       # 개발 서버
npm run build     # dist/ 생성
```
- React 18 + TypeScript + Vite + vite-plugin-pwa (오프라인 캐시)
- 구조: 모든 파일이 한 폴더에 있음 (빌드 때 `nkrv.json`→`dist/data/`, 아이콘→`dist/icons/`로 복사, `vite.config.ts` 참고)
- 성경 데이터: `nkrv.json` — `[책][장][절]` 배열
- 폰 저장: `localStorage` (`sk-bible-v1`)
- 문장으로 찾기: `sentenceSearch.ts` — 음절 2-gram 역색인 + BM25 (오프라인)
- AI 설명: `ai.ts`(앱) → `/api/ask` → `worker.js`(Cloudflare Worker, Workers AI `@cf/openai/gpt-oss-120b`, 실패 시 Llama 4 Scout)
  - 1단계 find: 질문 고쳐 쓰기 + 구절 후보 → 앱이 실제 본문 확인 → 2단계 explain: 설명 JSON
- 자동 업데이트·버전: `pwa.ts`, 빌드 때 `dist/version.json` 생성 (`vite.config.ts`)
- 뒤로 버튼: `utils.ts`(initBackHandling) + `store.ts`(navBack)
- 원어: `orig-1~9.json` (STEPBible TAHOT/TAGNT 가공, `[원어, 음역, 영어, 스트롱, 문법코드, 사전형, 뜻]`), `morph.ts`(문법 코드→한국어), `OriginalView.tsx`
- v1.5: `study.ts`(AI 요청·저장, 관주 `xref.json` `{"책.장.절":"책.장.절[-끝] …"}`), `StudyView.tsx`(해설 화면), `ChapterInfo.tsx`(배경 카드·책 소개), `bookinfo.ts`(66권 소개), `MemoryView.tsx`(암송); worker step `verse`·`lexicon`·`term`·`background`
- 소제목: `headings.ts` + `kheads.json`(개역개정 소제목 `{책: {장: [[절, 소제목, 관련 구절]]}}`), 장 주제는 `/api/ask` step `topic`
